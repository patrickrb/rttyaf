RTTYAF
Android RTTY · FT8AF / SSTVAF family
Clickable prototype. Palette, type (Inter + Geist Mono) and chrome are lifted from FT8AF so it reads as the same family. Tap callsigns in the RX pane to fill the entry, press a macro to transmit, and Log to push a QSO to the logger.
ASSUMPTIONS
· MYCALL KS3CKC, 20m RTTY at 14.084, standard 45.45 Bd / 170 Hz
· Contest exchange fields change per contest; casual mode hides them
· One logger active at a time; sync is per-QSO, retried on failure
· RX text is simulated; waterfall shows mark/space tone pairs
